## ✨ Возможности

* **Универсальный поиск:** поиск любого аниме по названию на русском, английском или ромадзи, а также по прямым ссылкам.
* **Мульти-источники:** поиск и агрегация релизов с YummyAnime, AnimeGO и AnimeVost.
* **Управление сезонами и сериями:** быстрый выбор нужного сезона, компактная навигация по эпизодам для онгоингов и пакетная загрузка всего сезона.
* **Озвучка и качество:** выбор студий перевода (AniLibria, StudioBand, AnimeVost, субтитры) и разрешения (до 1080p Full HD).
* **Встроенный плеер:** просмотр прямо в приложении с сохранением в локальное хранилище.
* **PWA-интеграция:** установка на компьютер или смартфон в один клик без ручной сборки APK или DMG.

## 📱 Установка

### Android
1. Откройте веб-версию в браузере **Google Chrome**.
2. В появившемся внизу баннере нажмите кнопку **«Установить»** (или меню `⋮` → **«Установить приложение»**).
3. Приложение появится на рабочем столе и будет запускаться в полноэкранном режиме.

### macOS
1. Откройте приложение в браузере **Safari**.
2. В верхнем меню выберите: **Файл** → **«Добавить в Dock…»**.
3. Запускайте AniMac Studio как отдельную программу.

### Windows
1. Откройте проект в браузере **Chrome** или **Microsoft Edge**.
2. Нажмите на значок установки в правой части адресной строки.
3. Программа появится в меню «Пуск» и на панели задач.

## 🛠 Локальная разработка

```bash
# Клонирование репозитория
git clone [https://github.com/Volodymyr2033/animac-studio.git](https://github.com/Volodymyr2033/animac-studio.git)
cd animac-studio

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Продакшен-сборка
npm run build
```
